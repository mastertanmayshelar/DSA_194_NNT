FAQs:-
FAQ'S Q1. What is UART? UART is a hardware communication protocol used to transmit and receive serial data between devices.

Q2. Why use a circular buffer for UART? It efficiently uses memory and allows continuous data transfer without shifting existing data.

Q3. What happens when the buffer is full? New data may be lost due to overflow unless the buffer is managed properly.

Q4. Is UART synchronous or asynchronous? UART is asynchronous because it does not use a separate clock signal for synchronization.

Q5. What is baud rate? Baud rate is the number of signal symbols transmitted per second; in typical UART, it corresponds numerically to bits per second.
